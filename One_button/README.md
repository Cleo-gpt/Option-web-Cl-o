## Agent

Un agent "contradicteur", spécialiste en code, est utilisé en complément lors du débogage.
Son seul rôle est de challenger les conclusions proposées — chercher les angles morts,
proposer des hypothèses alternatives, pointer ce qui n'a pas été vérifié — plutôt que de
confirmer la première explication trouvée. Objectif : croiser deux analyses indépendantes
avant de toucher au code.
