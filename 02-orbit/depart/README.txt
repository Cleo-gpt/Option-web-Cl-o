Départ — planètes (orbites)

Votre enseignant·e vous donne ce dossier. Vous pouvez aussi le
télécharger en ZIP si le dossier est sur GitHub (Code → Download).
Vous n’avez pas à forker ni à ouvrir un terminal.

Vous devez avoir exactement ceci avant d’écrire le JavaScript :

  sas/orbites/index.html          ← HTML déjà là
  sas/orbites/css/style.css       ← page nuit déjà prête
  sas/orbites/js/planete.js       ← classe à compléter

Le canvas est vide et le bouton Pause est visible au départ. C’est normal.
Votre travail se fait dans js/planete.js avec les étapes de
projets/02-orbites/2-ATELIER.pdf. Ouvrez-le après 1-COURS.pdf.

Quatre planètes seulement. Ce n’est pas le grand projet.
