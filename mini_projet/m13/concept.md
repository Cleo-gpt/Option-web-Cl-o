# Concept

Petit jeu 2D en HTML/CSS/JS vanilla.

Un personnage se déplace horizontalement sur une scène avec les flèches gauche/droite du clavier. 10 points de lumière sont disposés au sol, répartis régulièrement. Le joueur doit passer dessus pour les ramasser. Un compteur affiche la progression (x/10). Quand les 10 lumières sont ramassées, un message de victoire s'affiche.
