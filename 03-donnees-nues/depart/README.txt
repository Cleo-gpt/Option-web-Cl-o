Départ — données nues puis objet

Votre enseignant·e vous donne ce dossier. Vous pouvez aussi le
télécharger en ZIP s’il est disponible sur GitHub (Code → Download ZIP).
Vous n’avez pas à ouvrir un terminal.

Placez son contenu pour obtenir exactement cet arbre :

  sas/donnees-nues/index.html      ← tableau déjà prêt
  sas/donnees-nues/css/style.css   ← décor déjà prêt
  sas/donnees-nues/js/meule.js     ← squelette à trous

Ouvrez d’abord projets/03-donnees-nues/1-COURS.pdf, puis
projets/03-donnees-nues/2-ATELIER.pdf.

Au départ, les trois décisions sont écrites dans le tableau et les cartes
sont vides. C’est normal. Tableau d’abord, classe ensuite. Pas de billets.
