Départ — même objet, deux langages

Votre enseignant·e vous donne ce dossier. Vous pouvez aussi le
télécharger en ZIP si le dossier est sur GitHub (Code → Download).

  sas/deux-langages/index.html
  sas/deux-langages/css/style.css
  sas/deux-langages/js/billet.js
  sas/deux-langages/php/Billet.php
  sas/deux-langages/php/billets.php

Les étapes sont dans projets/06-deux-langages/2-ATELIER.pdf.
JavaScript d’abord, PHP ensuite. Pas de base de données.
