Règles du jeu

  • Chaque joueur commence avec 10 coeurs.
  • Une erreur (les 2 cartes ne correspondent pas) = -1 coeur.
  • Une paire trouvée = +1 coeur.
  • Un joueur à 0 coeur est éliminé.
  • Le but : rester en vie jusqu'à la fin de la partie.
  • Une lumière de couleur signale le joueur dont c'est le tour.
  • Chaque joueur a 45 secondes pour retourner 2 cartes.
